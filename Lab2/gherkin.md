# Gherkin сценарії (DimPenShelf)

Нижче наведені Gherkin-сценарії, що базуються на user stories. Кожен сценарій написаний у синтаксисі Gherkin із ключовими словами `Feature`, `Scenario`, `Given`, `When`, `Then`, `And` і має унікальний ідентифікатор (наприклад, `US-00-S1`).

Надано по 3 сценарії на кожну user story (US-00 … US-08), включно з граничними/негативними/альтернативними сценаріями (неавторизований спроба, відхилення оплати, відсутня служба доставки тощо).

---

## US-00 — Автентифікація та авторизація (попередня умова)

**Feature:** Автентифікація та авторизація користувача

```gherkin
Scenario: US-00-S1 Успішний вхід користувача
  Given неавторизований користувач знаходиться на сторінці входу
  When він вводить вірний логін та пароль і натискає "Увійти"
  Then система автентифікує користувача
  And система надає доступ до захищених дій

Scenario: US-00-S2 Вхід з невірними обліковими даними відхиляється
  Given неавторизований користувач знаходиться на сторінці входу
  When він вводить невірний логін або пароль і натискає "Увійти"
  Then система відхиляє вхід
  And система повідомляє про помилку автентифікації

Scenario: US-00-S3 Неавторизований користувач не може виконати захищену дію
  Given користувач не автентифікований
  When він спробує оформити бронювання книги
  Then система забороняє бронювання
  And система просить увійти в систему
```

## US-01 — Перегляд каталогу книг

**Feature:** Перегляд каталогу книг

```gherkin
Scenario: US-01-S1 Читач переглядає список книг із примірниками
  Given Читач зареєстрований та увійшов у систему
  When він відкриває сторінку каталогу книг
  Then система відображає список книг із назвою, автором та кількістю примірників
  And для кожної книги показується статус примірників

Scenario: US-01-S2 Читач перевіряє статус примірників конкретної книги
  Given у каталозі є книга "Гаррі Поттер"
  When Читач вибирає цю книгу
  Then система показує кількість доступних, зарезервованих, видані та примірники на реставрації

Scenario: US-01-S3 Читач пошукує книгу за назвою
  Given Читач знаходиться на сторінці каталогу
  When він вводить назву книги у пошуковий рядок
  Then система відображає книги, що відповідають пошуковому запиту
```

## US-02 — Бронювання книги

**Feature:** Бронювання книги

```gherkin
Scenario: US-02-S1 Читач успішно бронює доступний примірник
  Given Читач увійшов у систему
  And у книги є примірник зі статусом ДОСТУПНИЙ
  When Читач оформляє бронювання цього примірника
  Then система створює бронювання зі статусом ОЧІКУЄ ОБРОБКИ
  And дедлайн бронювання зберігається в UTC
  And статус примірника змінюється на РЕЗЕРВОВАНИЙ

Scenario: US-02-S2 Читач не може забронювати примірник у статусі РЕЗЕРВОВАНИЙ або ВИДАНО (IN_USE)
  Given примірник книги має статус РЕЗЕРВОВАНИЙ іншим Читачем або ВИДАНО (IN_USE)
  When Читач спробує оформити бронювання цього примірника
  Then система відмовляє в бронюванні
  And повідомляє, що примірник недоступний для бронювання

Scenario: US-02-S3 Читач переглядає свої активні бронювання
  Given Читач увійшов у систему та має активні бронювання
  When він відкриває розділ "Мої бронювання"
  Then система відображає список активних бронувань з термінами дії

Scenario: US-02-S4 Прострочене бронювання автоматично скасовується через TTL
  Given примірник книги має статус РЕЗЕРВОВАНИЙ та прострочений термін дії
  When вбудований механізм БД TTL спрацьовує
  Then статус примірника змінюється на ДОСТУПНИЙ
  And статус бронування стає ПРОТЕРМОВАНИЙ
```

## US-03 — Оплата оренди книги

**Feature:** Оплата оренди книги

```gherkin
Scenario: US-03-S1 Читач оплачує оренду успішно
  Given Читач увійшов у систему та оформив бронювання книги
  When Читач підтверджує оплату через Платіжну систему
  And Платіжна система авторизує списання коштів
  Then система створює квитанцію (Receipt) з дедлайном повернення
  And статус примірника змінюється на ВИДАНО (IN_USE)
  And статус оплати квитанції стає ПІДТВЕРДЖЕНО

Scenario: US-03-S2 Платіжна система відхиляє оплату
  Given Читач увійшов у систему та спробує оплатити бронювання
  When Платіжна система відхиляє оплату
  Then система не створює квитанцію
  And статус примірника не змінюється на ВИДАНО (IN_USE)
  And система повідомляє Читача про відмову в оплаті

Scenario: US-03-S3 Читач отримує підтвердження статусу оплати
  Given квитанція створена, але оплата ще не підтверджена
  When Платіжна система передає підтвердження статусу оплати
  Then система оновлює статус оплати квитанції на ПІДТВЕРДЖЕНО
```

## US-04 — Оформлення доставки

**Feature:** Оформлення доставки книги

```gherkin
Scenario: US-04-S1 Читач оформляє доставку при бронуванні
  Given Читач увійшов у систему
  And Служба доставки підключена до системи
  When Читач обирає доставку при оформленні бронювання
  Then система обчислює ціну та термін доставки через Службу доставки
  And Служба доставки генерує накладну

Scenario: US-04-S2 Читач отримує статус доставки
  Given замовлення передано Службі доставки
  When статус переміщення замовлення змінюється
  Then система передає інформацію про статус Читачеві
  And Читач бачить поточний статус доставки у системі

Scenario: US-04-S3 Читач не може оформити доставку, якщо Служба доставки відсутня
  Given Служба доставки не підключена
  When Читач намагається обрати доставку
  Then система не пропонує варіант доставки
```

## US-05 — Відгук та оцінка книги

**Feature:** Відгук та оцінка книги

```gherkin
Scenario: US-05-S1 Читач залишає оцінку та відгук
  Given Читач увійшов у систему та прочитав книгу
  When він ставить оцінку та пише текстовий коментар
  Then система зберігає відгук, пов'язаний із Читачем та книгою

Scenario: US-05-S2 Читач редагує власний відгук
  Given Читач увійшов у систему та має власний відгук на книгу
  When він змінює оцінку та коментар
  Then система оновлює відгук із новими даними

Scenario: US-05-S3 Читач видаляє власний відгук
  Given Читач увійшов у систему та має власний відгук на книгу
  When він видаляє відгук
  Then відгук більше не відображається для книги
```

## US-06 — Додавання книги та статистика (Автор)

**Feature:** Додавання книги та статистика Автора

```gherkin
Scenario: US-06-S1 Autor додає нову книгу
  Given Autor увійшов у систему
  When він додає книгу із назвою, автором та кількістю сторінок
  Then книга з'являється у каталіку
  And Autor є автором цієї книги

Scenario: US-06-S2 Autor переглядає статистику читань своїх книг
  Given Autor увійшов у систему та має книжки у каталіку
  When він відкриває розділ статистики
  Then система відображає статистику читань/продажів для кожної його книги

Scenario: US-06-S3 Відгуки Autorа візуально виділяються
  Given Autor увійшов у систему та залишив відгук на свою книгу
  When інший користувач переглядає відгуки книги
  Then відгук Autorа візуально виділяється
```

## US-08 — Отримання примірника (EARS-14)

**Feature:** Отримання примірника книги

```gherkin
Scenario: US-08-S1 Читач отримує примірник після успішної оплати
  Given Читач увійшов у систему та має бронювання зі статусом ОЧІКУЄ ОБРОБКИ
  When оплата через Платіжну систему авторизована успішно
  Then система створює квитанцію (Receipt) з дедлайном повернення
  And статус примірника змінюється на ВИДАНО (IN_USE)
  And Читач може забрати примірник

Scenario: US-08-S2 Читач не може отримати примірник без успішної оплати
  Given Читач увійшов у систему та має бронювання зі статусом ОЧІКУЄ ОБРОБКИ
  When Платіжна система відхиляє оплату
  Then система не створює квитанцію
  And статус примірника не змінюється на ВИДАНО (IN_USE)
  And Читач не може забрати примірник

Scenario: US-08-S3 Читач отримує примірник із дедлайном повернення
  Given Читач увійшов у систему та оплатив бронювання
  When Читач забирає примірник із бібліотеки
  Then система встановлює дедлайн повернення у UTC
  And статус примірника залишається ВИДАНО (IN_USE) до повернення
  And Читач отримує квитанцію з дедлайном повернення
```
